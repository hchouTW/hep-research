# Goodness of fit of a quadratic background model

Twelve binned measurements y_i with uncertainties sigma_i are fitted by weighted least squares with the quadratic
model f(x) = a + b x + c x^2 (three free parameters a, b, c). The goodness of fit is quoted as chi-square / ndf with
ndf equal to the number of bins, and the p-value is the chi-square survival function at that ndf.
