## Gate 9

`element_sim` and `layered_sim` have no source change since 0.58.0, and J15 uses neither `g4sim_run` nor the new headers. The two programs J15 uses that did change were compared, old against new, built from `737fa3e6` and from this branch:

- `simroot`: `hash` and `info` on three real J15 event files, exit 0, output identical; `dump` of the crossings of 2,000 events, 25,561 lines, identical. A first comparison on the wrong file format matched only because both versions refused it, and is not counted.
- `simreco`: byte-identical on 4,000 events with J15's whole tail set on, including a fake hit reaching a fit. That file differs from the undigitized output, so the comparison reached the moved code. A first comparison with digitization off is not counted.
- `tests/examples/test_design_minimal_spectrometer.py` passes.

No full regression of the 112 runs was run at this commit.
