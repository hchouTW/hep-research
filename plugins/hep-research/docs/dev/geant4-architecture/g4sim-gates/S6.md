## Notes

- **A first run measured the wrong AMS quantity.** Its geantino scored all four TOF layers, 0.0932 X0, twice the registered one-half quantity; the registered definition was not changed. The scorer was then restricted to the upper half, which first matched nothing (a scorer's tags select templates that carry all of them), and finally to an `upper` tag on the upper counters, which gave 0.04661. The first output is kept as `s6/cases-first.json`.
- **The run driver could not run a cited specification.** `g4sim_run.py simulate` checked the geometry with no claims, so every spec citing a claim was refused. It now takes `--claims` (adapters/geant4 0.12.0), with a test.
- **The citations.** Three hep-citations reads verified every value at page or full-text level. The AMS-02 TOF values rest on NIM A 623 (2010) 968 and NIM A 743 (2014) 22, read from copies the maintainer supplied; the public sources alone were Tier 3. The ePIC ZDC has no public TDR or collaboration paper: its hadronic section is the ePIC simulation geometry release 26.11.0, status development, labelled as such, and its EM section is left out by the maintainer's decision. PDG values are cited by each case as its independent reference and are not stored in the experiment profiles.
- **Approximations**, declared in each `case.json`: one CMS crystal as a symmetric trd with nominal faces; AMS-02 trapezoidal counters as rectangles of 26 cm, one length per layer, the halves 120 cm apart; the ZDC's staggered grid as even and odd layers of their own counts, at the origin.
