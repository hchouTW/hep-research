# T11: citation verification

The plugin text behind T11's cells cites sources nobody had re-read. On 2026-11-06 two reviewers checked 56 citation uses against the sources, on INSPIRE, arXiv and PDG. Verdicts apply to the statement each cell attributes to the source. Records: `<private>/evidence/t11-sources/t11-verify-a.json`, `t11-verify-b.json`. These sources are not yet in the literature record.

Result: 33 supported, 13 partly, 10 unread, 0 not supported. Read levels: 30 full text, 16 named sections (`page`), 8 `abstract+metadata`, 2 `metadata-only`. Reviewers' labels were normalized to the contract's terms. An `unread` verdict reflects access, not doubt: no open text was reached.
